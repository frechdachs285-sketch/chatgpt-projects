# RätselKids Musik-Assets

In diesen Ordner kommen die fünf Hintergrundmusik-Dateien für RätselKids.

Erwartete Dateinamen:

- rainbow.mp3
- adventure.mp3
- star_dance.mp3
- magic_forest.mp3
- dream_cloud.mp3

Die Dateinamen müssen exakt so bleiben, da `MusicService` diese Pfade bereits verwendet.

Bis die echten MP3-Dateien vorhanden sind, startet RätselKids keine Musikwiedergabe automatisch.
