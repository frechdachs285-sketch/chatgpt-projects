# RätselKids v0.6

Kindgerechte Rätsel-App für Kinder ab 5 Jahren.

## Stand

- 7 Rätselwelten
- 70 Rätsel
- Leicht / Knifflig / Gemischt
- zufällige Reihenfolge
- Rätseli-Begleitfigur
- deutsche Sprachausgabe
- Sterne, Bestleistungen und Abzeichen
- Elternbereich
- Sprache/Sound ein- und ausschaltbar
- lokaler Fortschritt
- Android-Testbuild-Vorbereitung
- Launcher-Icon-Konfiguration
- nativer Splashscreen
- Setup- und APK-Build-Skripte

Für die Android-Schritte siehe `README_ANDROID.md`.
